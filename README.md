# pdf-merge

##A quick and short projecct I created to merge pdf documents for a school project that required merging multiple submisisons into 1 pdf document.

How to use(**assuming you've forked and cloned and the repo and is residing in the root directory**):

1. Add you pdf files(they have to be in pdf) to the root directory(pdf-merge)
2. Open the merge.py file
3. Replace the values in the 'pdf_files' list with your own (use the base_dir / "{your file name}").
4. Save the file
5. Open your terminal in the project folder(you can right click the pdf-merge or press 'ctrl + `')
6. install the python package 'pip install pypdf'
7. run the file 'python merge.py'

**all pdfs will be merged and the output document will be "campus_market_final_v1.pdf"(you can change it by updating the value 'output_pdf' variable)**
